PORTFOLIO SKELETON: HOW TO USE

FILES
  index.html          Home
  about.html          About Me (education, work experience, skills)
  instructions.html   Instructions Assignment + 2-3 sentence intro
  job-materials.html  Cover Letter, Resume, Mini Interview
  proposal.html       Proposal Assignment + 2-3 sentence intro
  style.css           Colors and fonts (change the values at the top)

EDIT
  1. Open each .html file in a text editor (VS Code, Notepad, TextEdit in plain-text mode).
  2. Search for "YOUR NAME" and replace it everywhere.
  3. Replace each dashed placeholder box (<div class="placeholder">...</div>) with your content.
  4. Optional: make folders named "files" (PDFs) and "images" (photos) next to the HTML files.

DEPLOY FREE ON NETLIFY (easiest)
  1. Make a free account at netlify.com.
  2. Go to Sites > "Add new site" > "Deploy manually".
  3. Drag this whole folder onto the page.
  4. Click Site configuration > Change site name to get yourname.netlify.app.
  5. Submit that link. It must open the Home page directly.

BEFORE SUBMITTING: open the link in a private window, click every menu item, and confirm
no dashed placeholder boxes remain.
